# 相册图片目录

将相册图片直接放入此目录，支持以下格式：

- `.jpg` / `.jpeg`
- `.png`
- `.webp`
- `.gif`
- `.avif`
- `.heic` / `.heif`（启动或构建时自动转换为 JPEG）

页面会在启动或构建时自动读取图片。排序优先使用 EXIF 拍摄时间，没有拍摄时间时使用文件创建时间；时间越早越靠前。时间完全相同时再按文件修改时间和文件名稳定排序。

`.mov` 和 `.mp4` 属于视频，目前不会进入图片相册。浏览器兼容版本和排序清单会自动生成到 `public/album-generated/`，请勿手动修改该目录。

新增或删除图片后，如果开发页面没有自动刷新，请重新运行 `npm run dev`；发布版本需要重新运行 `npm run build`。
